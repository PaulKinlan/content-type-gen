content-type-gen

Each media file is the prompt — a bespoke page is generated around it (chapters, transcript, related links). This static build serves three pregenerated examples; the Deno server (server.ts) does it live for any file.

  • future-of-web.mp4 — a video presentation
  • napkin-drawing.mp4 — a napkin sketch turned into a page
  • voice-memo.mp3 — a voice memo turned into an app
